## 阿牛哥操作指引（生成 PAT，2 分钟）

1. 浏览器登录 GitHub 账号 **livsstock**
2. 右上角头像 → **Settings** → 左侧最底 **Developer settings**
3. **Personal access tokens → Fine-grained tokens** → **Generate new token**
4. 填写：
   - Token name: `workbuddy-push`
   - Expiration: 30 天（先短后长，跑稳了再续）
   - Repository access: **Only select repositories** → 选 `livsstock/xgl`
   - Permissions → Repository permissions → **Contents: Read and write**（其他全不勾）
5. **Generate token** → 复制以 `github_pat_` 开头的字符串，发给我
6. （备选）如果 fine-grained 生成麻烦，也可以用 classic token，只勾 `repo` 这一个大类也行

安全说明：token 只用于 push_wb.py 推送，不落盘（URL 临时使用），泄露风险最低的做法就是只授权这一个仓库的 Contents 权限。
