## 〇、仲裁智能体的三条铁律

1. **不预测**——仲裁体永远不输出涨跌判断，只对已有预测打分
2. **只读方向和结果**——不解析任何一方的 reason（判断理由），避免被叙事说服
3. **规则透明**——所有判定阈值写在本文档里，双方可验证、可复现

## 二、方向判定规则（核心——双方必须一致）

### 2.1 实际方向判定（v1.1 分轨制）

**指数（上证/创业板）：**

| 条件 | 判定 |
|---|---|
| 涨跌幅 > **+0.15%** | `up` |
| 涨跌幅 < **-0.15%** | `down` |
| \|涨跌幅\| ≤ 0.15% | `flat` |

**个股/ETF：**

| 条件 | 判定 |
|---|---|
| 涨跌幅 > **+0.05%** | `up` |
| 涨跌幅 < **-0.05%** | `down` |
| \|涨跌幅\| ≤ 0.05% | `flat` |

**阈值是死数字，不许调。** 拒绝相对值（振幅比例）方案的理由：相对值的实现细节（用当日还是 N 日均振幅、是否含集合竞价）会导致双方算出不同结果，违背"可复现"原则。要改必须走规则变更流程（见第九节）。

### 2.2 预测方向归一化

**WorkBuddy 格式**（已是英文）：
```
t1_prediction.sh_index.direction = "up" / "down" / "flat"
stock_calls[].direction = "up" / "down" / "flat"
```

**大海格式**（中文，映射表）：
```
verification.index_direction: 涨→up 跌→down 平→flat
market.direction: 偏多→up 偏空→down 震荡→flat（仅当 index_direction 缺失时用）
stocks[].t1_direction: 涨→up 跌→down 平→flat
```

**优先级**：`verification.index_direction` > `market.direction`（前者是明确的涨跌判断，后者是倾向）

### 2.3 方向命中判定

| 情况 | 结果 |
|---|---|
| 预测方向 == 实际方向 | **HIT**（计 1 分）|
| 预测 up 实际 down（或反之）| **MISS**（计 0 分）|
| 预测 flat 实际 up/down | **PARTIAL**（计 0.5 分）|
| 预测 up/down 实际 flat | **PARTIAL**（计 0.5 分）|
| 预测或实际缺失 | **NO_DATA**（不计入分母）|

**flat 的哲学**：flat 不是错误，是"明确说了不动"——市场真动了你只对一半，所以给半分。这个规则两边实现必须一致，否则胜率差好几个点。

## 三、区间命中规则

预测区间格式：`range_pct: [-0.3, 1.2]`（WorkBuddy）/ `"[-0.3%, +1.2%]"`（大海，字符串需解析）

| 判定 | 规则 |
|---|---|
| **HIT** | 实际涨跌幅 ∈ [下界, 上界]，闭区间 |
| **MISS** | 落在区间外 |
| 缺失 | NO_DATA |

**闭区间**：正好落在边界（如实际 +1.2% 且上界 1.2）算 HIT。

## 四、标的对账规则

### 4.1 对账范围

标准标的池 26 只（见第一节映射表）。**只对双方都出了判断的标的打分**（交集），单方判断不计分。

### 4.2 action → 隐含方向

双方 action 字段五花八门，统一映射：

**WorkBuddy：**
```
含 "sell" → down
含 "buy" / "watch" / "hold" → up
其他 → NO_DATA
```

**大海：**
```
优先 t1_direction（涨/跌/平，明确）
缺失时 fallback action："买/关注/轻仓/标准仓" → up；"卖/减仓" → down
```

### 4.3 大海格式特殊处理

大海的 `stocks` 是 `{"股票名": {...}}` 结构：
1. 股票名 → 代码（用第一节的映射表，含别名兼容）
2. 映射不到的标的 → 跳过并记 log（比如他写了新股票我们池里没有）
3. 同一标的多个别名同时出现（如"半导体ETF"和"芯片ETF"）→ 取第一个出现的

## 五、置信度校准规则

| 项 | 规则 |
|---|---|
| 归一化 | `"60%"` → 0.6；`0.6` 原样；`>1` 的数值再除以 100 |
| 校准偏差 | `实际胜率 - 平均自称置信度` |
| **高估** | 偏差 < -0.05（说 60% 实际只有 45%）→ 标 ⚠️，下周置信度强制下调 |
| **低估** | 偏差 > +0.05 → 标 🧊，可以适度上调 |
| **良好** | \|偏差\| ≤ 0.05 → ✅ |

## 六、分歧仲裁规则（仲裁体独有）

### 6.1 分歧定义

**标的层面**：双方对同一标的的隐含方向一个 up 一个 down（flat 不算分歧，算 PARTIAL）。

**指数层面**：双方 sh_index 方向相反。

### 6.2 机械仲裁（v1.1 双裁判并列制）

**两个并列裁判，同时计算：**

- **裁判 A（趋势）**：20 日均线方向——现价 > MA20 判多，< MA20 判空，±0.5% 内判模糊
- **裁判 B（量能）**：量比 ≥ 1.3（较 5 日均量放大 30%）且当日有明确涨跌方向（±0.15%）→ 按当日方向

**仲裁规则：**

| 情况 | 裁决 |
|---|---|
| 裁判 A 与裁判 B **同向** | 按此方向仲裁 |
| 裁判 A 与裁判 B **矛盾** | **不强行裁决** → 观望/半仓（矛盾本身就是降仓信号）|
| 裁判 A 模糊 | 单独看裁判 B；裁判 B 也无效 → 观望 |
| 裁判 B 无效（量比 < 1.3 或当日 flat）| 单独看裁判 A |

**背景条件（VIX 偏移）**：VIX ≥ 25（恐慌态）时，所有仲裁结果向保守方向偏移一档——up → 观望，观望 → 建议减仓。VIX 只是偏移器，不单独裁决。

**设计说明（为什么不让量能优先）**：量在价先是对的，但放量下跌破位（量能对）与放量假摔洗盘（量能陷阱）在当天无法区分。双裁判矛盾时选择观望，是把"分不清"显式化为仓位动作，而不是赌某一边的胜率。

### 6.3 仲裁胜负记录

每个分歧标的收盘后记录：
```
{code, wb_dir, dh_dir, arbiter_verdict, actual_dir, arbiter_correct}
```

**累计 ≥10 个分歧样本后**，输出权重建议：
```
建议权重 = 分歧胜率占比（WB 赢 6 次 DH 赢 4 次 → WB:0.6 DH:0.4）
只建议不生效——生效需系统所有者（阿牛哥）批准
```

### 6.4 宏观-技术背离日判定（v1.1 修订统计口径）

| 背离类型 | 判定条件 | 处理 |
|---|---|---|
| 顶背离预警 | 宏观偏多（美股涨+A50涨）+ 技术超买（RSI6 > 68）| 降仓预警 ⚠️ |
| 底背离预警 | 宏观偏空（美股跌+A50跌）+ 技术超卖（RSI6 < 25）| 关注反包 💡 |
| 变盘预警 | 双方指数方向相反 + 上述任一背离 | 强降仓 ⚠️⚠️ |

**背离日统计口径（v1.1）：计入总胜率 + 打标签单独统计。**

背离日的预测**正常计入总胜率**（不排除），同时在 scoreboard 里单独维护一行"背离日胜率"。最终评估模型时看两个数：

1. **常规胜率**——整体水平
2. **背离日胜率**——关键时刻的判断力（区分模型真实能力的最重要指标）

> v1.0 曾规定"背离日不计入普通胜率"，v1.1 废除该条。理由（大海提出，阿牛哥采纳）：背离日是市场最重要的决策时刻，排除它等于把最难的题划出考场，反而掩盖模型的真实能力差异。

## 七、三层记分牌规则（v1.2 新增 · 阿牛哥指示：准确率是过程，赚钱才是目的）

> **设计动机**：两个模型胜率都到 70% 也没用——如果该抓的超跌反弹没抓到、慢牛拿不住、乱开火亏掉本金，准确率就是自嗨。记分牌从单一"胜率"升级为三层结构，终极指标是**模拟 P&L**。

### 7.0 三层结构总览

| 层 | 名称 | 回答的问题 | 性质 |
|---|---|---|---|
| **L1** | 准确率 | 方向/区间/个股说得对不对？ | 过程指标（原第二~五节规则不变）|
| **L2** | 机会捕获 | 赚钱机会来了，你事前给信号了吗？ | **核心指标** |
| **L3** | 假信号 | 你开的火，有没有烧到自己？ | 风控指标 |
| **终极** | 模拟 P&L | 按你的信号操作，到底赚不赚钱？ | 裁决性指标 |

### 7.1 L2 机会捕获（事后机会 + 事前捕获）

**机会定义（事后识别，用 stock_data + 后续收盘价）：**

| 类型 | 判定条件 | 机会起始日 |
|---|---|---|
| 超跌反弹 | 某标的当日 `technical.change_10d_pct ≤ -10%`，且其后 **5 个交易日内**收盘价较起始日收盘反弹 `≥ +5%` | 10 日跌幅触发的当天 |
| 慢牛 | `trend_score` 连续 **5 个交易日 ≥ 60**，且区间累计涨幅 `≥ 3%` | 连续 5 天确认的当天 |

**捕获判定（事前）：** 机会起始日的**前 1~3 个交易日**内，模型对该标的给出过看多类信号：

- WorkBuddy：`stock_calls[].action` 含 `watch` 或 `buy`
- 大海：`stocks[].action` 含 `买 / 关注 / 轻仓 / 标准`

**捕获率 = 捕获数 ÷ 机会数**（区间内同类机会合并统计；同一标的同一次机会双方各记各的）。

### 7.2 L3 假信号（风控）

| 项 | 规则 |
|---|---|
| 定义 | watch/buy 信号发出后 **5 个交易日内**，收盘价较信号日收盘**再跌 ≥ 5%** |
| 计数 | 每个信号只记 **1 次**（先触发先记，不重复累计）|
| 分母 | 当期发出的 watch/buy 信号**总数**（不是捕获数）|
| 假警报率 | 假警报数 ÷ 信号总数 |

### 7.3 终极指标：模拟 P&L（双方必须实现一致）

> **v1.3 起分轨**：核心池白名单内标的走**长效轨**，白名单外走**短线轨**（见 §7.7）。下表为短线轨规则。

**交易规则（只用收盘价，双方可复现）：**

| 项 | 短线轨 | 长效轨（白名单）|
|---|---|---|
| 入场 | **信号日收盘价** | 同左 |
| 止盈 | 收盘价较入场 **≥ +5%** → 平仓 | **无**（长效股拿住不动）|
| 止损 | 收盘价较入场 **≤ -5%** → 平仓 | **≤ -15%** → 平仓（防崩盘底线）|
| 强平 | 持有满 **10 个交易日** | 持有满 **20 个交易日** |
| 仓位 | 每信号 **10%** | 每信号 **20%** |
| 累计 | `累计P&L% = Σ(单笔收益率% × 该轨仓位)` | 同左 |

**为什么用收盘价而非次日开盘价**：开盘价数据不稳定、复现困难；信号 8:35 盘前发布，当天收盘可执行。

### 7.4 三层联读（给阿牛哥的看板）

| 症状 | 诊断 |
|---|---|
| L2 高 + P&L 负 | 抓得住机会但**拿不住**——信号发太早被止损，或发太晚吃不到肉（择时问题）|
| L2 低 | **看不见机会**——方向说得头头是道，反弹来了没喊单（感知问题）|
| L3 高 | **乱开火**——信号满天飞，一半是假警报（风控问题，应压缩信号数量提高门槛）|
| L1 高 + L2 低 + P&L 平 | **答题型模型**——胜率好看但不产生交易价值 |

### 7.5 信号分类标签（预测方义务，v1.2 起）

WorkBuddy 预测 schema v2.2 起，每个 `stock_calls[]` 增加 `signal_type` 字段：

```
signal_type: "oversold_rebound"（超跌反弹类：watch_rebound / buy_rebound）
             "slow_bull"        （慢牛持有类：hold / hold_partial_profit）
             "none"            （观望/卖出）
```

大海侧不强制改格式——仲裁体按 action 关键词自动归类（买/关注/轻仓 → 视同 oversold_rebound 类看多信号，除非大海后续自行打标）。此标签用于分类型统计"反弹类信号质量"和"持有类信号质量"。

### 7.6 数据依赖

- L2 机会识别：`stock_data_YYYYMMDD.json`（`change_10d_pct` / `trend_score`）+ 后续 `daily-finance-*.json` 的收盘价
- L3 假信号 & P&L：仅 `daily-finance-*.json` 的 `watchlist[].close`
- 样本不足（区间 < 6 个交易日）时 L2 返回空，不扣分——首周冷启动正常现象

### 7.7 核心池与分轨考核（v1.3 新增 · 阿牛哥 9/19 指示）

> **背景**：26 只对齐后，预测火力集中到重点赚钱标的。WorkBuddy 与大海各自提名六股，经机械仲裁合并，**阿牛哥 2026-09-19 结构裁决（严格6只·趋势优先）**，**9/20 大海独立判定（commit c3f0d76）修订超跌第4席后定稿为核心池 v2.2**（`config/core_pool.json`）：**4 只超跌反弹 + 2 只慢牛长效**，仓位 4×10% + 2×20% = 80%，留 20% 现金缓冲。

**分轨规则（按白名单，与预测格式无关 → 双方口径自动一致）：**

| 轨 | 适用标的 | 仓位 | 止盈 | 止损 | 结算周期 | 信号判定关键词 |
|---|---|---|---|---|---|---|
| **短线轨** | 白名单**外**所有标的（含观察池 watch/buy）| 10% | +5% | -5% | 10 交易日强平 | watch / buy |
| **长效轨** | 白名单**内**标的（`slow_bull` 名单）| 20% | **无** | **-15%** | 20 交易日期末结算 | watch / buy / hold |

**分轨设计理由**：用 ±5% 止损考核慢牛股，会把正常回调震出场——长效股的价值在于"拿得住"。硬止损放宽到 -15% 是**防崩盘**底线，不是交易策略。

**关键约定：**
1. **白名单是唯一分轨依据**——不依赖 action 命名，双方读同一个 `core_pool.json`（缺失时全按短线轨），避免解析歧义
2. **观察池的 hold 不算交易**——只有白名单股的 hold 计入 P&L，防止 20 只观察池的 hold 稀释核心考核
3. **L3 假警报阈值同步分轨**——短线轨 5 日内再跌 ≥5%，长效轨 20 日内再跌 ≥15%
4. **L2 机会捕获仍按 26 只全量统计**——机会识别是客观的，不因核心池而缩小视野（避免"因为没选它所以假装没看到机会"）

**核心池维护：** 调仓需阿牛哥批准，建议**月度复审**。复审判据：连续 20 交易日跑输同期指数 → 降为观察位；观察位标的 MA20 转上行 + 趋势分回升 → 递补。

### 7.8 评分公式精确规范（v1.4 新增 · 大海质询"裁判需要同一把尺子"）

> **背景**：金钼股份同一标的两边超跌判断截然相反（WorkBuddy 超跌分0 vs 大海半月-15.25%深跌）。经40日K线实测核对：**两边都没算错，是窗口不同**——金钼15日前跌约12%，最近10日横盘-2.53%。本节把所有评分公式精确到可复现，双方必须实现一致。

**数据基准（所有公式的前提）：**
- K线源：腾讯 `proxy.finance.qq.com/ifzqgtimg/appstock/app/newfqkline/get`，日K，**qfq 前复权**
- 收盘价序列 `closes`：`closes[-1]` = 当日，`closes[-k]` = k 个交易日前
- 样本不足（n < 所需条数）时该指标置 `null`，不计分

**涨跌幅字段（v2.2 采集起双窗口 + 高点回撤）：**
```
change_10d_pct = (closes[-1] / closes[-11] - 1) × 100
change_15d_pct = (closes[-1] / closes[-16] - 1) × 100   ← 大海半月口径，2026-09-19新增
dd_30d_pct = (closes[-1] / max(closes[-31:]) - 1) × 100 ← 近30日高点回撤，恒≤0，2026-09-20新增（大海提议）
```

**RSI6（Wilder 平滑，周期6）：**
```
首周期：avg_g = 前6日涨幅均值, avg_l = 前6日跌幅均值（跌幅取正）
迭代：  avg_g = (avg_g×5 + 当日涨幅)/6，avg_l 同理
RSI6 = 100 - 100/(1 + avg_g/avg_l)
```

**MACD（标准 12/26/9）：**
```
DIF = EMA(12) - EMA(26)，EMA 首值取首日收盘
DEA = DIF 的 EMA(9)
signal: DIF上穿DEA→golden_cross；下穿→death_cross；否则neutral
```

**oversold_score（0-100，三项累加封顶；v1.5 修订跌幅分量）：**
```
RSI6 分量：  RSI6 < 20 → +40；20 ≤ RSI6 < 30 → +25；30 ≤ RSI6 < 40 → +10；≥40 → 0

跌幅档位表（三口径共用，chg 恒为负值）：
  chg < -20% → 40；[-20,-15) → 30；[-15,-10) → 20；[-10,-5) → 10；≥-5% → 0

跌幅分量（v1.5：三口径取最深档位）：
  drop = max(档位(change_10d), 档位(change_15d), 档位(dd_30d))

底背离分量： DIF ≤ min(DIF[-20:]) 且 change_10d < -5% → +20

oversold_score = min(RSI6分量 + drop + 底背离分量, 100)
```

**v1.5 修订理由（大海 9/20 提议 + 26只实测验证）**：10/15日窗口捕捉"近期急跌"（阴跌型），30日高点回撤捕捉"深跌后横盘"（错杀型）——典型案例金钼股份：10日-2.53%（横盘）但30日回撤-17.11%，纯窗口口径得0分会系统性漏掉错杀型标的。三口径取最深使两类形态都入网。实测排序变化：北稀25→55、华友20→50、金钼0→30、锡业/盛和/隆基0→30浮出。**注意**：茅台型"阴跌不止"（RSI超卖但回撤仅-7.24%）在技术分上仍可能居前，入选超跌轨还须过"可操作性"（一手成本≤单票仓位金额）与"错杀形态"（回撤深度）检验——见 §7.7 观察位说明。

**trend_score（0-100，clamp[0,100]）：**
```
MACD golden_cross → +30；death_cross → -20
closes[-1] > MA20 → +20；MA5 > MA10 → +15；closes[-1] > MA5 → +15；closes[-1] > MA10 → +10
```

**分轨用的尺子（v1.4 澄清——防止再用错）：**

| 指标 | 设计用途 | **不得用于** |
|---|---|---|
| oversold_score | 短线轨：超跌反弹时机 | — |
| trend_score | 短线轨：趋势强度 | ~~判定长效轨标的资格~~（压舱石低波动是设计属性）|
| MA20 | 环境诊断 + 双裁判A | ~~绩优超跌股的入场闸门~~（错杀本就发生在MA20下方）|

**长效轨 P&L 计量修正（分红缺口）：** 压舱石标的年化股息约 5-6%，但 daily-finance 的 `close` 是**未复权盘口价**，除息日会显示为下跌——价格 P&L 系统性低估长效股。**规则：长效轨标的的 P&L 结算改用前复权价**（即 K 线 `qfqday` 的 close，分红已含入），短线轨维持盘口价（反弹周期内通常无除息，且口径简单）。仲裁体实现时须区分这两个价源。

**质量闸门（阿牛哥铁律）：绩优 + 超跌 ≥10% 才做，亏损股超跌要谨慎。** 当前 oversold_score 不含基本面分量；ROE/业绩数据源列入 v2.2 采集路线图，落地后超跌分增加第四分量：`ROE_TTM ≥ 8% → +20`（绩优加成），双方再对齐。在那之前，超跌信号的质量过滤由预测方在 thesis 中人工背书。
