## 变更 1：数据文件迁到 `data/daily` 分支

## 变更 3：新增 manifest.json（开机体检用）

### 文件结构
```json
{
  "_说明": "LIVS-Stock 每日数据索引，大海盘前用作开机体检",
  "generated_at": "2026-09-15T09:35:22+08:00",
  "branch": "data/daily",
  "count": 30,
  "entries": [
    {
      "date": "2026-09-15",
      "filename": "daily-finance-2026-09-15.json",
      "raw_url": "https://raw.githubusercontent.com/livsstock/xgl/data/daily/output/daily-finance-2026-09-15.json",
      "quality": "complete",
      "updated_at": "2026-09-15T08:01:34+08:00"
    },
    ...
  ]
}
```

### data_quality 字段定义
- `"complete"` — 6 个源全部成功
- `"partial"` — 至少 1 个源失败（非关键源全部失败 或 1 个关键源失败）
- `"failed"` — 2 个以上关键源失败

**大海模型读取建议**：
```pseudo
if manifest.entries[0].quality != "complete":
    log.warn("今日数据质量 = {quality}, 部分源失败, 拒绝跑预测")
    return "数据异常"
else:
    fetch daily-finance.json
    run v12.7
```
