## stock_data_YYYYMMDD.json 结构（大海直接对接这个文件）

**文件位置：** `https://raw.githubusercontent.com/livsstock/xgl/data/daily/output/stock_data_YYYYMMDD.json`
**更新节奏：** 每日 08:00 北京时间（交易日）
**大小：** ~13 KB / 20 只股

### 顶层字段

```json
{
  "_说明": "stock_data 格式：大海 daily_forecast.py 输入",
  "_schema_version": "1.0",
  "date": "2026-09-18",
  "generated_at": "2026-09-18T15:08:00+08:00",
  "count": 20,
  "skipped": [],
  "stocks": [...]
}
```

### 单只 stock 结构

```json
{
  "code": "601398",
  "name": "工商银行",
  "close": 8.07,
  "pre_close": 8.14,
  "open": 8.09,
  "high": 8.17,
  "low": 8.06,
  "volume_hand": 2466427.0,
  "turnover_wan": 199683.0,
  "turnover_yi": 19.97,
  "turnover_rate_pct": 0.09,
  "change_pct": -0.86,
  "technical": {
    "macd": {
      "dif": 0.0809,
      "dea": 0.072,
      "macd": 0.0178,
      "signal": "neutral"  // golden_cross / death_cross / neutral
    },
    "rsi6": 58.35,
    "change_10d_pct": 0.49,
    "volume_ratio": 0.97,
    "turnover_rate_pct": 0.09,
    "oversold_score": 0,        // 0-100, 越高越超跌
    "trend_score": 45           // 0-100, 越高越强势
  }
}
```

### 关键字段说明（大海写作必读）

| 字段 | 范围 | 解读建议 |
|---|---|---|
| `macd.dif - macd.dea` | 正负 | MACD 柱强度 |
| `macd.signal` | 三态 | golden_cross=金叉买入 / death_cross=死叉卖出 / neutral=观望 |
| `rsi6` | 0-100 | <20 超卖 / 20-30 弱势 / 30-70 中性 / >70 超买 |
| `change_10d_pct` | -100 ~ +100 | 10日累计涨跌幅 |
| `volume_ratio` | 0 ~ ∞ | <0.8 缩量 / 0.8-1.2 正常 / 1.2-2.0 温和放量 / >2.0 巨量 |
| `oversold_score` | 0-100 | ≥60 强超跌候选 / ≥40 一般超跌 / <20 不超跌 |
| `trend_score` | 0-100 | ≥70 强势 / 40-70 中性偏多 / <40 弱势 |

### composite 信号灯（大海直接拿）

```python
def composite_signal(stock):
    tech = stock["technical"]
    if tech["trend_score"] >= 70 and tech["macd"]["signal"] == "golden_cross":
        return "STRONG_BUY"
    if tech["oversold_score"] >= 60 and tech["rsi6"] < 25:
        return "OVERSOLD_BUY"
    if tech["trend_score"] <= 30 and tech["macd"]["signal"] == "death_cross":
        return "SELL"
    return "HOLD"
```

## manifest.json 双索引

每条 entry 现在含两个 raw URL：

```json
{
  "date": "2026-09-18",
  "filename": "output/daily-finance-2026-09-18.json",
  "raw_url": "https://raw.githubusercontent.com/livsstock/xgl/data/daily/output/daily-finance-2026-09-18.json",
  "stock_data_filename": "output/stock_data_20260918.json",
  "stock_data_raw_url": "https://raw.githubusercontent.com/livsstock/xgl/data/daily/output/stock_data_20260918.json",
  "quality": "complete",
  "updated_at": "2026-09-18T15:08:00+08:00"
}
```

大海的扣子智能体读 `entries[0].stock_data_raw_url` 即可拿到个股技术数据。
