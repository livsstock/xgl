## 二、关键发现：T+1 全正，T+3 全负

| 阶段 | 表现 |
|---|---|
| **T+1** | 7 条中 6 条为正（+0.05 ~ +1.64） |
| **T+3** | 全部转负 |
| **T+5** | 继续下跌 |

**这说明什么？**

**信号确实抓到了短线反弹——但反弹只持续 1 天。**

模型抓到的是**"下跌途中的反抽"**，不是**"底部反转"**。这两者在交易上完全不同：
- 反抽：1 天，抄进去就被埋
- 反转：持续，可以持有

**模型把"反抽"当成了"反转"来推荐。**

## 三、我原本的改进方案，实测无效

### 提案：趋势过滤

```
原提案：
  超跌反弹信号前置条件：
    个股收盘 ≥ MA20 × 0.98   OR   大盘收盘 ≥ MA20
```

**动机**：9/21 那批票大多深度偏离 MA20（-2.5% ~ -5.8%），过滤掉它们应该能改善结果。

### 实测结果（用 9/21 数据回测）

⚠️ **9/21 当天大盘在 MA20 上方**（3949.91 vs MA20 3922.42，偏离 **+0.70%**）。

**"或大盘≥MA20"这一条，把 6 只全部放过了——过滤条件完全失效。**

```
保留 6 只，平均 T+5: -5.60%
不过滤 6 只，平均 T+5: -5.60%
提升: +0.00 个百分点
```

### 我又试了 5 种变体，全部失败

## 四、真正的根因

### 根因 1：样本太小，单边行情主导

9/21–9/30 期间上证 **-2.63%**，是一个**单边下行段**。

**在下行段里做多，方向本身错了**，与选股逻辑无关。这也解释了为什么 6 种过滤全部失效——**它们都在优化"怎么选多头"，而问题在于"该不该做多"。**

### 根因 2：核心池构成偏弱

| 标的 | 9/21 相对 MA20 |
|---|---|
| 五粮液 | **-0.79%**（贴近均线） |
| 北方稀土 | -2.54% |
| 金钼股份 | -2.77% |
| 华友钴业 | -4.79% |
| 紫金矿业 | -5.84% |
| 半导体ETF | +3.96%（唯一在均线上） |

**5/6 已跌破 MA20。** 在这样的池子里选"反弹标的"，等于**在弱势股里找强势**。

### 根因 3：RSI bug 放大了信号（已修复）

`calc_rsi()` 此前是简单平均而非 Wilder，**RSI 系统性偏低 8–13 点**，导致"超卖"信号虚增。

**这个 bug 已在 9/29 修复，但历史推荐受影响。**

## 五、改进方案（修正版）

### 关键转变：从"优化选股"转向"判断该不该做多"

前面 6 种过滤全部失败，说明**在个股层面做过滤是错的方向**。真正的杠杆在**仓位层面**。

### 改进 A：大盘状态门（最高优先级）

```
在产生任何买入信号前，先判定大盘状态：

  ① 大盘 ≥ MA20 且 MA20 上行       → 进攻（可产生买入信号）
  ② 大盘 ≥ MA20 但 MA20 下行       → 谨慎（仅观察，不推荐）
  ③ 大盘 < MA20                    → 防御（禁止买入信号）
```

**验证**：9/21 时 MA20 是上行还是下行？

> **实测结果（重要）**：
> ```
> 09-18  MA20=3922.09  收盘=3911.87  偏离 -0.26%
> 09-21  MA20=3922.42  收盘=3949.91  偏离 +0.70%
> MA20 方向: 上行 ▲ (3922.09 → 3922.42)
> ```
>
> ⚠️ **9/21 被判为「① 进攻状态」——大盘状态门也拦不住它。**

**为什么失效？** 大盘 9/21 恰好收在 MA20 上方（+0.70%），且 MA20 微幅上行（+0.33 点，几乎走平）。

**这是个真实的教训**：9/21 那天**从任何常规技术指标看都是"健康"的**——大盘在均线上、MA20 微升。**但随后 6 个交易日跌了 3.26%。**

**因此改进 A 需要补充维度**（待与大海讨论）：
- MA20 斜率**强度**（+0.33 点 / 20 日 ≈ 几乎走平，应判为"走平"而非"上行"）
- 或引入**大盘振幅/波动率放大**作为预警
- 或采用**多周期共振**（MA5 与 MA20 同向）

**这一条我暂不下定论**——因为单一样本无法验证，需要更多历史数据。**先在方案里标注为"待验证"。**

### 改进 B：超跌反弹降级为"观察"，不产生买入信号

**在单边下行段，"超跌"只是状态描述，不是交易信号。**

```
原：RSI6<30 + 单日收红  →  buy/watch_rebound
改：RSI6<30 + 3日止跌确认 + 大盘状态允许  →  watch（仅观察）
    只有在①状态下，且止跌确认成立，才升级为 buy
```

### 改进 C：三档止跌确认（替代"单日收红"）

```
① 连续 2 日收盘不创新低
② 最近 3 日均量 < 前 5 日均量（缩量）
③ 出现下影线 或 阳线实体覆盖前一日阴线
```

**三条全满足才算确认。** 9/21 北方稀土写的"周五+0.35%止跌"，只满足 0 条。

### 改进 D：建立信号台账（**已实现**）

```bash
python3 reconciliation/tools/gate_ledger.py --signal-scan    # 自动扫描建档
python3 reconciliation/tools/gate_ledger.py --signal-stats   # 胜率统计
```

**这是治本的一条**——有了台账，每个信号对错可查，**不靠事后悔悟**。
