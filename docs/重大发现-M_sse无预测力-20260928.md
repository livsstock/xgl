# 🔴 重大发现：M_sse 的方向预测能力等于随机基线

> 生成：2026-09-28 17:00 ｜ 复核样本：280 个交易日（2025-07 ~ 2026-09）
> 结论先行：**当前 M_sse 模型预测大盘次日方向的能力，与"永远猜中性"完全一致，且低于"永远猜涨"。**

---

## 一、先说这条结论是怎么来的（我返工了三次）

这一轮我错了三次，每次都以为找到了根因，都被下一轮数据推翻。**过程本身比结论更值得记录**：

| 轮次 | 我的判断 | 怎么被推翻的 |
|---|---|---|
| 1 | "Kuramoto R 方向反了，改成方向加权就好" | 从 JSON 输出**反推**公式，反推错了（把 R_15 当成 15 分钟动量，实际是 15 **个交易日**涨跌幅） |
| 2 | "是 Kuramoto 常数偏移，剥离后 9/24 就判对了" | 复现值 43.7 vs 线上 49.4，**差 5.7 分** —— 这个偏差让我起了疑心，去翻了源码，发现真的错了 |
| 3 | "改 Kuramoto 能修复" | 用**源码精确公式**重跑 280 天，五个变体命中率全在 30% 附近，改了个寂寞 |

**如果我在第 1 轮就下结论去改模型，改的一定是错的方向。**

## 二、证据链（全部可复现）

### 证据 1：Kuramoto 分量确实没有分辨力（这条判断成立）

用源码公式 `phases = [atan2(p, 10) for p in change_pcts]` 复现 280 个交易日：

```
min = 0.9184    max = 0.9979
均值 = 0.9790   标准差 = 0.0136
变异系数 = 1.39%          （对比：股票价格变异系数通常 5~20%）
与当日涨跌相关系数 r = +0.1112   →  无显著相关
```

原因：涨跌幅典型范围 ±3%，而 `atan2(p, 10)` 把它压缩到 **±16.7°** 的极窄扇区，26 只股票相位全挤在一起，`R = |Σe^{iθ}|/N` 几乎必然趋近 1。

**但——去掉它并不会变好**（见证据 3）。所以它不是病根。

### 证据 2：M_sse 分布严重右偏，长期在喊多

```
min 24.4   p10 47.7   p25 53.3   p50 60.8   p75 67.0   p90 73.3   max 89.7
均值 60.4   标准差 10.4
```

对照现有阈值 **BULL=60 / BEAR=40**：

| | 占比 |
|---|---|
| M_sse ≥ 60（判看多） | **54.6%** |
| M_sse ≤ 40（判看空） | **3.2%** |
| 40 < M_sse < 60（判中性） | 42.1% |

> **模型在 54.6% 的交易日喊"看多"，只有 3.2% 喊"看空"。**
> 而这段样本期（2025-07 ~ 2026-09）大盘实际是**震荡下行**的。

### 证据 3：改阈值完全无效，五套方案命中率全在 30%

| 阈值方案 | BULL | BEAR | 命中率 | 判多% | 判空% |
|---|---|---|---|---|---|
| 现状 60/40 | 60.0 | 40.0 | **31.4%** | 54.6% | 3.2% |
| p70/p30 | 65.9 | 55.0 | **31.4%** | 30.0% | 30.4% |
| p75/p25 | 67.0 | 53.3 | 28.2% | 25.0% | 25.4% |
| p80/p20 | 69.2 | 51.3 | 29.6% | 20.0% | 20.4% |
| p85/p15 | 71.6 | 49.1 | 31.1% | 15.0% | 15.4% |

用分位数重标定后，"看空"占比从 3.2% 提到 30.4%，**但命中率纹丝不动（31.4%）**。

**→ 说明信号本身没有预测力，不是阈值切得不对。**

### 证据 4（最关键）：随机基线对照

| 策略 | 命中率 |
|---|---|
| **M_sse 现状** | **31.4%** |
| 永远猜"中性" | **31.4%** ← **完全一样** |
| 永远猜"涨" | **37.9%** ← **比 M_sse 还高 6.5 个点** |
| 永远猜"跌" | 30.7% |
| 今天跌 → 明天猜跌 | 32.9% |

**实际方向分布**：涨 37.9% ／ 跌 30.7% ／ 平 31.4%

> **M_sse 的表现，和"闭着眼睛永远说中性"一模一样。
> 并且不如"闭着眼睛永远说涨"。**

## 三、这意味着什么

### 3.1 不是"参数需要调"，是"这套信号没有预测力"

我原本以为修 Kuramoto、调阈值就能解决。数据显示：**五个不同的口径、五套不同的阈值，命中率全都钉在 28%~32%**。

这不是"还没找到好参数"，这是**信号本身不含信息**。

### 3.2 为什么之前没发现

因为**没有人算过命中率**。

我们一直在讨论"9/24 判错了""9/28 对齐了"，都是**单日个案**。个案可以找出无数理由（那天数据不好、那天有突发消息）。**只有跑完 280 天整体统计，才能看出真相。**

这是我们建系统以来最大的一个盲区：**有预测、有对账、有假设跟踪，但没有回测命中率。**

### 3.3 一个必须承认的可能性

**大盘次日涨跌，可能本来就接近不可预测。**

业界早有共识：日频方向预测的信噪比极低。上面"永远猜涨 37.9%"这个数字很说明问题 —— 在样本期里，随便猜涨就能赢过复杂模型。

**这不代表模型没用，代表我们选错了预测目标。**

---

## 四、该怎么办（三个方向，不是修 bug）

### 方向 A：改变预测目标（我推荐）

**放弃"预测次日涨跌"，改做"识别趋势状态"。**

| 现在 | 改后 |
|---|---|
| 输出 `up/down/neutral` | 输出 `趋势/震荡/破位` |
| 每天都要给方向 | 只在状态明确切换时报警 |
| 追求方向命中率 | 追求"状态识别准确率 + 切换及时性" |

理由：趋势状态（`9/28 五线粘合后向下突破`）比次日涨跌**稳定得多、可验证得多**。9/28 我判断"破位非回调"，这个判断哪怕次日反弹也不一定错——它描述的是**概率结构**，不是单点预测。

### 方向 B：只用高置信度信号

**不追求每天都给方向，只在极端读数时出手。**

例如：只有当 M_sse < 30 或 > 80（样本中约 5% 的交易日）才输出方向，其余一律 `neutral`。

需要先验证：**这些极端日的命中率是否显著高于 31%？** 如果高，说明模型"偶尔有用"；如果还是 31%，说明彻底没用。

**这个验证我可以立刻做。**

### 方向 C：承认局限，把系统改造成"风控工具"而非"预测工具"

不预测方向，改为：
- 监控风险指标（五线粘合、宽度骤降、量能异常）
- 触发预警（"当前处于高不确定状态，建议降低仓位"）
- 只做**减法**（什么时候不该买），不做**加法**（什么时候该买）

说实话，这个定位可能比"预测大盘"更符合实际需求 —— 用户的核心诉求是"跌了要不要加仓"，那是**风控问题**，不是预测问题。
