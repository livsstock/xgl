## 一、三层结构

| 层 | 处理 | 说明 |
|---|---|---|
| ① 原始凯利 | f* = (p·b − q) / b | 用实测胜率p、赔率b |
| ② 折减 | ×0.5(半凯利) ×drift系数 ×级别系数 | 应对估计误差与信号衰减 |
| ③ 硬约束 | 单标的≤20% 总仓≤60% 低于2%不操作 | 防凯利在估计误差下爆仓 |

drift 系数用你的四档方案（≤3pt=1.0 / 3-6=0.7 / 6-10=0.4 / >10=0）。

## 二、一个硬口径（老板拍板）
