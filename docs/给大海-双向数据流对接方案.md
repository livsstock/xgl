## 二、你流向我的（需要你做，3选1，按成本从低到高）

### 方案 A：扣子工作流加一个"预测输出"节点（推荐）

你的扣子工作流跑完 LLM 预测后，加一个 **HTTP 请求节点**把预测结果推上来：

```
[你的LLM预测节点] → [HTTP POST 节点] → GitHub API 提交
```

**GitHub API 提交（一行 URL，PUT 方法）：**

```
PUT https://api.github.com/repos/livsstock/xgl/contents/predictions-dahai/YYYY-MM-DD.json
```

Headers:
```
Authorization: Bearer <阿牛哥给你的token>
Accept: application/vnd.github+json
```

Body（content 是你的预测 JSON base64 后的字符串）：
```json
{
  "message": "dahai prediction YYYY-MM-DD",
  "content": "<你的预测JSON转base64>"
}
```

Python 生成 base64：`base64.b64encode(json.dumps(pred).encode()).decode()`
