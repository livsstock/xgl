### 4.4 所以正确的修法是

```python
def extract_market_direction(data, source="wb"):
    # WB 数据：大盘方向从顶层 index.change_percent 推算
    idx = data.get("index") or data.get("_market_environment", {}).get("index", {})
    if isinstance(idx, dict):
        chg = idx.get("change_percent")
        if chg is None:
            chg = idx.get("chg_today_pct")     # 兼容旧字段名
        if chg is not None:
            if chg <= -0.5:
                direction = "bearish"
            elif chg >= 0.5:
                direction = "bullish"
            else:
                direction = "neutral"
            return {"direction": direction, "confidence": None,
                    "reason": f"上证涨跌{chg}%",
                    "source": "index.change_percent"}
    # ... 再走兜底
```

**关键是 `data.get("index")` 在顶层，不是在 `_market_environment` 下面。**

按你现在的代码，**`extract_market_direction` 每次都返回 `unknown`**，然后被洞 3 的 fail-closed 拦成 HIGH。
