## 技术细节

### 1. 美股接口迁移（新浪 → 腾讯）

**旧（已失效）：**
```
https://finance.sina.com.cn/stock/usstock/api/jsonp_v2.php/...?symbol=.DJI
→ HTTP 404
```

**新（腾讯，与 A 股同源）：**
```
https://qt.gtimg.cn/q=usDJI,usINX,usIXIC,usHXC
```
字段布局与 A 股完全一致：`[3]`=现价 `[4]`=昨收 `[32]`=涨跌幅，
可直接复用 `tx_index()` 解析逻辑。

### 2. 双 UA 降级策略

```python
def http_get(url, encoding="utf-8", referer=None):
    ua_list = [UA, UA_BROWSER]   # 先合规 UA，403 后换浏览器 UA
    for i, ua in enumerate(ua_list):
        try:
            ...
        except HTTPError as e:
            if e.code in (401, 403) and i + 1 < len(ua_list):
                continue  # 换 UA 重试
            raise
```

**影响范围：** 所有走 `http_get()` 的数据源自动受益。

### 3. K 线接口更换

**旧（失效）：**
- `web.ifzq.gtimg.cn/appstock/app/fqkline/get` → HTTP 501
- `quotes.sina.cn/.../getKLineData` → HTTP 456（限流）

**新（腾讯前复权日线）：**
```
https://proxy.finance.qq.com/ifzqgtimg/appstock/app/newfqkline/get?param=sh601398,day,,,35,qfq
```
返回字段：`[日期, 开, 收, 高, 低, 成交量(手), {}, 换手率%, 成交额(万), ...]`
- **单位直接是"手"**，与盘口字段一致，无需转换（比新浪更省事）
- 保留新浪作为降级源
