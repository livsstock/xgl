## 三、基线漂移惩罚 · 具体方案

你要的可落地方案：

**1. 窗口划分**
- test窗：最近252个交易日（约1年）
- train窗：test窗之前的全部历史，再按252天滚动切分看稳定性
- baseline每季度末重估一次，不实时变（避免规则抖动）

**2. drift定义**
- drift = train_baseline胜率 − test_baseline胜率（单位：百分点，正值=规则退化）
- 同时看均收漂移：train均收 − test均收

**3. 惩罚系数（对历史edge线性打折）**

| drift（胜率退化） | 系数 | 处理 |
|---|---|---|
| ≤3pt | 1.0 | 正常使用 |
| 3–6pt | 0.7 | 降权 |
| 6–10pt | 0.4 | 仅辅助参考 |
| >10pt | 0 | 停用，进观察区 |

- 调整后edge = 历史edge × 系数
- 任一规则 test窗胜率低于50%或test均收≤0，无论drift多少，直接停用
- 用Wilson score下界代替原始胜率参与计算，惩罚小样本虚高

## 四、稀有强信号样本量不足 · 换什么检验

大样本z检验/卡方在n<30时失效，改用：

1. **Fisher精确检验**（2×2命中×涨跌列联表）——小样本首选，不依赖渐近假设
2. **置换检验**（permutation test，重采样≥10000次）——信号标签随机打乱，看真实edge在零分布中的分位，适合"5天均收"这类连续指标
3. **置信区间用Wilson score**（胜率）或**Clopper-Pearson精确区间**——报告区间下界，不报点估计
4. **贝叶斯Beta-Binomial**：先验Beta(1,1)，得后验Beta(1+x,1+n−x)，直接算 P(胜率>0.55 | 数据)；后验概率>0.9才算强信号。样本越少先验拉得越狠，自动防止3/3=100%这种伪信号
5. 多重检验配套：样本少时BH-FDR不稳定，用**Storey q-value**或贝叶斯FDR；n极小（<10）的规则一律不单独决策，只允许和其他信号叠加

**一句话**：样本少就用精确检验+贝叶斯收缩，宁可判"证据不足"，不许3次命中就封神。
