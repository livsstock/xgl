# 给大海 · 硬约束方案落地：T5 高位滞涨

**2026-09-30**

上封信我说"需要一条不依赖模型方向判断的客观价格硬约束"，但当时**还不知道具体是什么**。

现在回测做完了，方案确定：**T5 高位滞涨**。

---

## 一、规则定义

```
T5:  20日区间分位 ≥ 70%   且   收盘对 MA20 偏离 < 1%
```

| 条件 | 含义 |
|------|------|
| `pos20 ≥ 70%` | 股价在近 20 日区间的高位（距最低点已涨 70% 以上）|
| `dev_ma20 < 1%` | 但没远离 MA20（贴着均线，涨幅追不上）|

**这两个条件合起来描述的是"高位滞涨"** —— 价格到区间上部（涨过一波），却贴着均线（动能衰竭），是典型的顶部形态。

## 三、必须排除的方向：MA 类规则（全部失败）

我测了 11 条基于均线的规则，**全部是负收益**：

| 规则 | 下跌率 | 触发均收 | 基线均收 | 规避收益 |
|------|--------|---------|---------|---------|
| 跌破MA20 | 43.7% | +0.21% | +0.08% | **-0.13%** |
| 跌破MA20超3% | 27.0% | +1.30% | +0.08% | **-1.22%** |
| 连破≥3日 | 41.9% | +0.29% | +0.08% | **-0.22%** |
| 连破≥5日 | 41.0% | +0.36% | +0.08% | **-0.28%** |
| 5日跌超3% | 35.2% | +1.01% | +0.08% | **-0.93%** |
| 5日跌超5% | 30.0% | +1.95% | +0.08% | **-1.87%** |
| 10日跌超5% | 19.0% | +1.66% | +0.08% | **-1.58%** |
| MA5<MA20且下行 | 43.2% | +0.23% | +0.08% | **-0.15%** |
| 四线全破 | 42.8% | +0.27% | +0.08% | **-0.19%** |

### 两条特别反直觉的

**"5 日跌超 5%" → 后续下跌率 30%，均收 +1.95%**
**"10 日跌超 5%" → 后续下跌率 19%，均收 +1.66%**

**大盘急跌之后反而该买。** 用这类规则避险，是在反弹前一刻卖出。

**"跌破 MA20 超 3%" → 下跌率 27%，均收 +1.30%**，躲开少赚 1.22 个点。

### 原因

**均线是滞后指标。** 等大盘跌破 MA20，跌幅往往已经走完，接下来是反弹。**用它避险 = 卖在底部。**

**不要实现任何 MA 类避险规则。** 这轮已经证实过了。

## 四、实现代码

```python
def high_level_stall(bars, i):
    """
    T5 高位滞涨：20日区间分位 >= 70% 且 收盘对 MA20 偏离 < 1%

    bars: [{date, open, close, high, low, vol}, ...]  按日期升序
    i   : 当前 bar 索引
    """
    w = bars[max(0, i - 19): i + 1]
    if len(w) < 20:
        return False

    lo = min(x["low"] for x in w)
    hi = max(x["high"] for x in w)
    if hi <= lo:
        return False

    pos20 = (bars[i]["close"] - lo) / (hi - lo) * 100
    ma20 = sum(x["close"] for x in w) / len(w)
    dev = (bars[i]["close"] / ma20 - 1) * 100

    return pos20 >= 70 and dev < 1
```

## 六、使用注意事项

| 项 | 建议 |
|---|------|
| **触发后动作** | **降级**（暂停超跌策略），**不是清仓** |
| 有效期 | 触发期间持续生效，条件解除即恢复 |
| 9/21 效果 | 触发 → 6 只超跌标的不会进推荐 |
| 覆盖率 | 1500 天里触发 135 天（**9%**），代价可控 |
| 概率含义 | 下跌率 64.8%，**不是 100%** |

**切记是"降级"不是"看空"。** 它说的是"这里风险偏高"，不是"一定跌"。

### 7.2 dev 阈值可以放宽（取舍问题）

| dev_ma20 | 覆盖率 | 下跌率 | 均收 | vs 基线 |
|----------|--------|--------|------|---------|
| **1** | **9.0%** | **64.8%** | **-0.51%** | **+17.1pt** |

## 八、一个必须交代的更正

**我第一版回测用的是 400 天样本（1.6 年），结论是"T5 无效"（p=0.187）。**

拉到 1500 天后结论**完全反转**：

| | 400 天 | 1500 天 |
|---|---|---|
| 独立事件 | 16 | **54** |
| 下跌率 | 50.0% | **64.8%** |
| p 值 | 0.187 ❌ | **0.002 ✅** |

**原因：400 天样本只有 16 个独立事件，统计力严重不足。**

**教训：验证一个避险信号，至少需要 50 个独立事件。** 400 天（约 1.6 年）看着挺多，实际只够采到 16 个独立事件。这个坑我踩了，写出来给你参考。
