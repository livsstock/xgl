## 四、根因分析

### 根因 1：核心池的构成有问题 —— 全是弱势股

| 标的 | 9/21 时 MA20 偏离 | 29日大盘位置 |
|---|---|---|
| 五粮液 | **-0.35%** | 接近均线 |
| 华友钴业 | 深度偏离 | 弱势 |
| 紫金矿业 | 深度偏离 | 弱势 |
| 金钼股份 | 深度偏离 | 弱势 |
| 北方稀土 | 深度偏离 | 弱势 |
| 半导体ETF | +5.10% | 前期强势 |

**核心池 6 只里 5 只处于下行趋势。** 在一个已经开始走弱的大盘里（9/21 已是顶部区 3952），推荐这批票等于**逆势抄底**。

### 根因 2：「超跌反弹」逻辑未被验证过

推荐逻辑的隐含假设：

```
跌得多 + RSI低 + 单日止跌  →  会反弹
```

**这个假设从未被回测验证。** 我们只在**大盘层面**验证过 M_sse 命中率（31.4% ≈ 随机），**个股层面的"超跌反弹"胜率完全是空白**。

### 根因 3：RSI 计算 bug 导致信号虚增（已修复）

9/29 发现 `calc_rsi()` 注释写 Wilder、实际是简单平均，**导致 RSI 系统性偏低 8–13 点**。

| 标的 | 错误值 | 正确值 | 后果 |
|---|---|---|---|
| 半导体ETF | 18.4 | 37.4 | **本不该触发** |
| 机器人ETF | 14.6 | 30.6 | **本不该触发** |

**这意味着 9/21 那批"RSI 深度超卖"的判断，有一部分建立在错误的数值上。**

### 根因 4：缺"止跌确认"机制

北方稀土的推荐理由写着"周五 +0.35% 止跌"——**用单日涨幅判断止跌**。

正确的止跌确认至少需要：
- 连续 2–3 日不创新低
- 缩量（卖压衰竭）
- 出现下影线或反包

## 五、改进方案

### 改进 1：加趋势过滤（**核心改动**）

**原则：只在 MA20 上方或大盘走强时，才启用"超跌反弹"逻辑。**

```
超跌反弹信号前置条件（AND）：
  ① 个股收盘价 ≥ MA20 × 0.98      （贴近或站上均线）
  ② 或 大盘收盘价 ≥ MA20          （大盘走强时放宽个股要求）
```

**反例验证**：按此规则，9/21 的 5 只逆势票**全部会被过滤掉**，只留五粮液——**而五粮液正是唯一赚钱的那只**。

### 改进 2：止跌确认从 1 日改为 3 日

```
止跌确认（替代原"单日收红"）：
  ① 连续 2 个交易日收盘价不创新低
  ② 且最近 3 日均量 < 前 5 日均量（缩量）
```

### 改进 3：超卖阈值分级，且必须用真实 Wilder RSI

| 级别 | RSI6 区间 | 动作 |
|---|---|---|
| 关注 | 30–35 | 仅观察 |
| 超卖 | 25–30 | 观察 + 需止跌确认 |
| 极端超卖 | < 25 | 需止跌确认 **+ 趋势过滤** |

**且必须确保 RSI 是真实 Wilder 算法**（已修复）。

### 改进 4：建立个股信号台账（**已实现**）

见 `reconciliation/tools/gate_ledger.py --signals`：

```bash
python3 gate_ledger.py --signal-add 2026-09-30 601899 buy
python3 gate_ledger.py --signals          # 查看所有信号及其后续表现
python3 gate_ledger.py --signal-stats     # 胜率/超额收益统计
```

**目的**：让每一个买入信号都可追溯、可证伪。**不再靠事后回忆判断对错。**
