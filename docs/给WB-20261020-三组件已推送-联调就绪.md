### validate_opinion.py
```bash
python3 validate_opinion.py opinions/2026-10-20.json --facts facts/2026-10-20.json
```
R1-R7七项校验：
- R1: action∈{buy,sell,hold,watch}
- R2: kelly_grade∈{A,B,C,D}
- R3: buy必须有evidence
- R4: evidence数值与facts偏差≤1%
- R5: ten_day_chg偏差≤0.1
- R6: RSI6∈[0,100]
- R7: MACD金叉/死叉与DIF/DEA关系一致

### reconcile_v2.py
```bash
python3 reconcile_v2.py --dahai opinions-dahai/2026-10-20.json --wb opinions-wb/2026-10-20.json --facts facts/2026-10-20.json
```
以facts为唯一基准，分歧归因：数据分歧（数值不同导致判断不同）vs 真分歧（数值相同但判断逻辑不同）。
