# 给大海：LIVS-Stock 数据对接（极简版）

**30-45 分钟搞定，全鼠标配置，零代码。**

---

## 你只需要知道 2 个 URL

```
清单（每天更新）：https://raw.githubusercontent.com/livsstock/xgl/data/daily/output/manifest.json
当日数据：      https://raw.githubusercontent.com/livsstock/xgl/data/daily/output/daily-finance-2026-09-15.json
```

`manifest.json` 里有个字段叫 `quality`，3 个值：
- `complete` ✅ — 数据全，正常预测
- `partial` ⚠️ — 部分缺失，告知用户哪些字段空
- `failed` ❌ — 直接回复"数据异常，请人工核实"，**不预测**

---

## 在扣子搭 4 个节点

### 节点 1 — HTTP 请求（名字：`读manifest`）

| 字段 | 填这个 |
|---|---|
| URL | `https://raw.githubusercontent.com/livsstock/xgl/data/daily/output/manifest.json` |
| 方法 | GET |
| 超时 | 10000 ms |
| Header | `User-Agent: LIVS-Stock-Coze-Bot/1.0 (research)` |

---

### 节点 2 — 选择器（名字：`质量判断`）

**分支 1（如果）：**
```
{{读manifest.entries.0.quality}} == "complete"
```
↓ 走到节点 3

**分支 2（否则如果）：**
```
{{读manifest.entries.0.quality}} == "partial"
```
↓ 直接结束（返回 partial 标记）

**分支 3（否则）：**
↓ 直接结束（拒绝预测）

> 如果点号语法报错，改成 `$.entries[0].quality`

---

### 节点 3 — HTTP 请求（名字：`读当日数据`）

仅在分支 1 执行。

| 字段 | 填这个 |
|---|---|
| URL | `{{读manifest.entries.0.raw_url}}` |
| 方法 | GET |
| 超时 | 15000 ms |

返回的就是完整 JSON（约 12 KB），**直接喂给 LLM 节点就行**，不用解析。

---

### 节点 4 — LLM（你的 LIVS-Stock v12.7）

系统提示词末尾加这几行：

```markdown
## 数据获取约定（强制）

1. 每次做"今日 / 最新"预测前，先调用 `livs_daily_data` 工具。
2. 工具返回 quality=failed → 回复"今日数据源异常"，不预测。
3. 工具返回 quality=partial → 顶部告知"以下板块缺失：[列出空字段]"。
4. 任何时间引用以工具返回的 date 字段为准，不用模型内部时间。
```

用户消息：
```
请帮我看今天盘前，给出今日 A 股方向判断。
```

---

## 把工作流变成智能体的工具

1. 工作流右上角 → **发布** → **发布为插件**
2. 插件名：`livs_daily_data`
3. 工具描述填这句：

> 获取最近一个交易日（A股）的完整财经数据包（指数、A50期货夜盘、VIX、涨跌家数、融资余额、自选股），返回结构化 JSON。数据源失败会自动降级并标注。

4. 在 LIVS-Stock v12.7 智能体里挂上这个插件

---

## 验证 3 步

1. **试运行节点 1** → 应该看到完整的 manifest JSON
2. **完整跑一遍工作流** → 节点 3 应该返回 12 KB 的数据
3. **在智能体对话框输入"今天盘前怎么样"** → 应该看到模型引用了"2026-09-15"的数据，不是模型自编

---

## 遇到问题？

- **节点 1 报 404**：检查是不是 `data/daily` 分支（不是 main）
- **节点 2 表达式不识别**：换 `$.entries[0].quality`
- **节点 3 拿不到数据**：节点 2 没走分支 1（先确认 quality 是不是 complete）
