## 二、规则的精确定义（避免理解偏差）

```
触发条件：
    pos20   = (收盘 - 近20日最低) / (近20日最高 - 近20日最低) × 100
    ma20    = 近20日收盘的简单平均
    dev_ma20 = (收盘 / ma20 - 1) × 100

    当  pos20 ≥ 70   且   dev_ma20 < 1   时触发
```

### 几个容易出错的地方，请你重点核对

| 项 | 我的口径 | 请你确认 |
|---|---------|---------|
| **"近20日"是否含当日** | **含**（取 `[i-19, i]` 共 20 根）| ❓ |
| 最高/最低用哪个价 | **high / low**（不是 close）| ❓ |
| MA20 用哪个价 | **收盘价简单平均**（不是 EMA）| ❓ |
| 是否复权 | **前复权 qfq** | ❓ |
| 独立事件合并阈值 | **间隔 ≤3 个交易日**合并为一段 | ❓ |
| 事件收益起算点 | **段首日收盘** → T+5 收盘 | ❓ |
| 交易日历 | **A股实际交易日**（跳过周末与假期）| ❓ |

**其中"近20日是否含当日"最易出错。** 如果含当日，pos20 的分母会随当日波动变化；如果不含，口径完全不同。我用的是**含当日**。
