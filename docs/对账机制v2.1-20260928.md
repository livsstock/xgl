**9/24 实际收盘**：`3888.37`，**-1.22%**

### 根因分析（已用线上源码精确公式验算，复现误差 0.8 分）

> ⚠️ **本节经过两次更正**。我第一版说"R_value 方向反了"，第二版说"是常数偏移"，**两版都不完整**。
> 现在拿到了 `daily_predict.py` 的源码（420-490 行），以下是**用精确公式复算的结果**。

**线上真实公式**

```python
# R_15 —— 注意！这是 15 个【交易日】涨跌幅，不是 15 分钟
r15_raw = (closes[-1] / closes[-16] - 1) * 100
r15 = max(0, min(100, 50 + r15_raw * 5))          # ±10% 打满

r_ma20dev = max(0, min(100, 50 + ma20_dev_pct * 5))

breadth = (up_count / valid_count) - 0.5
breadth_score = max(0, min(100, (breadth + 0.5) * 100))

# Kuramoto —— 这里是问题所在
phases = [math.atan2(p, 10) for p in phase_data]   # 涨跌幅 -> 相位
r_kura = sqrt(cos_sum**2 + sin_sum**2) / len(phases)
kuramoto_score = max(0, min(100, r_kura * 100))    # r_kura≈0.99 -> 恒得 99 分

m_sse_v25 = 0.3*r15 + 0.2*r_ma20dev + 0.3*breadth_score + 0.2*kuramoto_score
```

**9/24 精确复算**

| 分量 | 原始值 | 映射 | 权重 | 贡献 |
|---|---|---|---|---|
| R_15（15交易日） | **-1.36%** | 43.2 | 0.3 | 12.96 |
| MA20 偏离 | **-1.06%** | 44.7 | 0.2 | 8.94 |
| 板块宽度 | 6/26 = 23% | 23.1 | 0.3 | 6.92 |
| **Kuramoto** | **0.99** | **99.0** | **0.2** | **19.80** |
| **M_sse v2.5** | | | | **48.6** |
| *线上实际记录* | | | | *49.4* |

**复现误差 0.8 分**（盘中快照与收盘数据的时点差），**公式已确认等价**。

**剥离 Kuramoto**：`(12.96+8.94+6.92)/0.8 = **36.0**` → 落入 `<40` 看空带。
**Kuramoto 抬升水位：+12.6 分**（此前我估算 +19.8，是把权重算重了，以 12.6 为准）。

### 缺陷的准确表述

之前我说"方向反了"——**不准确**。`atan2(p, 10)` 对涨跌幅是**保号**的，涨跌方向信息其实被编码进了相位。

真实问题是：**相位映射函数 `atan2(p, 10)` 的量程被压缩了。**

- 涨跌幅 `p` 的典型范围是 **±3%**，而 `atan2(p, 10)` 在 `p∈[-3,3]` 时只覆盖 **±16.7°**
- 26 只股票的相位全部挤在 `-17° ~ +17°` 这个**极窄扇区**内
- 因此 `R = |Σe^{iθ}|/N` **几乎必然趋近 1**（矢量方向再散，角度范围小，合力方向依然一致）
- 实测 `r_kura` 恒在 **0.90~1.00**

**结论：Kuramoto 分量的分辨力被映射函数吃掉了。它形式上在算同步性，实际上输出一个几乎恒定的高位读数。**

### 影响量化

| 指标 | 设定 | 含 Kuramoto 偏移后实际等效 |
|---|---|---|
| MSSE_BULL | 60 | **47.4** |
| MSSE_BEAR | 40 | **27.4** |

看空门槛实际是 **27.4 分**，而 9/24 的 M_sse = **48.6** —— **差 21 分，判不出 down**。

### 三层叠加的缺陷

| 层 | 问题 | 后果 |
|---|---|---|
| **特征层** | `atan2(p,10)` 量程压缩，R 失去分辨力 | 恒定 +12.6 分抬水位 |
| **阈值层** | BULL/BEAR 未针对该偏移校准 | 看空门槛实际是 27.4 而非 40 |
| **决策层** | 中性带 (`40≤M<60`) 直接输出 neutral | 轻微偏空无法表达 |

### 修复方案（三选一，需大海确认）

**方案 A（推荐）**：修正相位映射量程
```python
phases = [math.atan2(p, 3) for p in phase_data]   # 10 -> 3，让 ±3% 覆盖 ±45°
# 或直接改成方向敏感版：
kura_score = 50 + 50 * r_kura * (1 if (r15_raw + ma20_dev_pct) >= 0 else -1)
```

**方案 B**：Kuramoto 权重 0.2 → 0.1，腾出的 0.1 给板块宽度（纯方向性指标）。

**方案 C**：阈值重标定，BULL/BEAR 从 60/40 调到 **72/52**（补偿 12.6 分偏移）。

我倾向 **A + C 组合**。但按纪律，**v2.5 是双方共同确认的口径，改它必须走对账流程**，不能我单方面改。这条写进给大海的同步信。

### 6.2 第二轮回测（用源码精确公式）：结论出乎意料

拿到了源码公式，重跑 280 个交易日：

**检验 1：Kuramoto R 确实没有分辨力（实锤）**

```
样本 280   min=0.9184   max=0.9979   均值=0.9790   标准差=0.0136
变异系数 1.39%        （对比：股票价格变异系数通常 5~20%）
与当日涨跌相关系数 r = +0.1112   → 无显著相关
```

**R 有 99% 的样本落在 0.98 附近，实质是个常数。** 我关于"Kuramoto 分量无分辨力"的判断**成立**。

**检验 2：但修复它解决不了问题 ← 这是最重要的发现**

| 口径 | 方向命中率 | 均分 |
|---|---|---|
| v2.5 现状 | 88/280 = **31.4%** | **60.4** |
| A 量程修正 `atan2(p,3)` | 90/280 = **32.1%** | 58.7 |
| A2 方向加权 | 89/280 = **31.8%** | 53.1 |
| B 降权 0.1 | 87/280 = **31.1%** | 55.2 |
| noR 去掉 Kuramoto | 83/280 = **29.6%** | 51.1 |

**五个口径全部落在 30% 附近，差异在噪声范围内。去掉 Kuramoto 反而更差（29.6%）。**

**→ 修复 Kuramoto 不能提高准确率。我原先"改 Kuramoto 就能修好"的判断是错的。**

**检验 3：真正的病根在阈值，不在特征**

注意"均分"那一列：**v2.5 现状均分 60.4，而 BULL 阈值是 60。**

这意味着 **M_sse 长期运行在"看多"区间**。而这段样本期（2025-07 ~ 2026-09）大盘整体是**震荡下行**的。

```
模型长期偏乐观（均分 60.4  >  BULL 60）
    ×
样本期实际偏空
    ↓
方向命中率 31%
```

**这才是 31% 的成因。** 不是某个分量坏了，是**整个 M_sse 的零点/量纲与阈值不匹配** —— 四个分量的映射函数（`50 + x*5`、`(b+0.5)*100`）把它们都推到中位数 50 以上，叠加后系统性偏高。
