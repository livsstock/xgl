## 我这边加了什么

### 1. 往返校验 `roundtrip_check.py`（新增，已接入每日流程）

不再靠"看着差不多"，而是**用他的算法复算他的数**，判定三类：

- **可复现** → 算法一致，分歧是真分歧（有样本价值）
- **不可复现** → 算法/数据不一致（假分歧，样本作废）
- **整数估值** → 疑似人工写的

每天自动跑，输出 JSON + CSV，人工可直接核对。

### 2. 修正表加了硬闸门

`correction_table.py` 现在先看往返校验结果：
- 通过 → 正常算仓位
- 不通过 → **全部归零**，并在输出里写明原因

这条比"2% 门槛"更靠前——**口径不对，后面所有计算都是白算**。
