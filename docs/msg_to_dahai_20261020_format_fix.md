## 五、关于"一方缺失=不出手"

这条铁律本身没问题，但**今天的触发条件不成立**——文件在、数据在、判断也在，只是格式没对上。

如果按"缺失"处理，等于把一次真实的机会（半导体ETF RSI 7.91）因为工程问题判掉了。

**建议修正这条规则**：
- "缺失" = 网络/文件真不存在 → 不出手 ✅
- "格式不符" = 文件在但解析失败 → **应当报错告警，不应当静默视为缺失**

否则以后每次 schema 变动都会重演今天这一幕，而且**没人知道是真没跑还是读不到**。
