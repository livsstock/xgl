## 二、核心发现：MA 类规则全线失败（400 天与 1500 天结论一致）

所有基于"跌破均线"的避险规则，在两个样本上都是**负收益**：

### 1500 天样本

|------|------|--------|--------|---------|---------|---------|

**全部为负。** 尤其是：
- **R8/R9：大盘急跌超 5% 之后，下跌率只有 19~30%，均收 +1.66~1.95%** —— 跌了反而该买
- **R4：跌破 MA20 超 3%，下跌率 27%，均收 +1.30%** —— 躲开少赚 1.22 个点

> **"跌破均线就避险"这个直觉，在数据上是错的。**

### 为什么

均线是**滞后指标**。等大盘跌破 MA20 时，跌幅往往已经走完，接下来是反弹。用它做避险，正好买在反弹前、卖在下跌后。

## 三、T5 是什么，为什么它不一样

```
T5:  20日区间分位 ≥ 70%   且   收盘对 MA20 偏离 < 1%
```

两个条件同时满足才触发：

| 条件 | 含义 |
|------|------|
| `pos20 ≥ 70%` | 股价处在近 20 日的**高位区**（距低点已涨 70% 以上） |
| `dev_ma20 < 1%` | 但**没有远离 MA20**（贴着均线，涨幅没跟上） |

**这个组合描述的是"高位滞涨"**：
股价到了区间上部，说明涨过一波；但贴着 MA20，说明**上涨动能在衰竭** —— 价格上不去，均线追不上来。

和"跌破均线"的区别：T5 是**在下跌发生之前**就能看到的形态，不是等跌完了才反应。

## 五、为什么 400 天样本给出了相反结论

| | 400 天（2025-02 ~ 2026-09） | 1500 天（2020-07 ~ 2026-09） |
|---|---|---|
| T5 触发日 | 171 | 135 |
| **聚成独立事件** | **16** | **54** |
| 事件下跌率 | 50.0% | **64.8%** |
| 随机对照 p | 0.187 ❌ | **0.002 ✅** |
| 判定 | 无效 | **有效** |

**原因：400 天样本只有 16 个独立事件，统计力严重不足。**

16 个事件里 8 涨 8 跌，看起来"完全没区分度"。但 54 个事件时，规律显现出来了。

> **教训：判断一个避险信号，至少需要 50 个独立事件。400 天样本是不够的。**

## 六、建议的落地方式

### 6.1 T5 作为独立风控层，不替代模型判断

```
第 1 层  大盘风控门（大海 v2 已有）
         ├─ 双方看空 → CRITICAL 冻结
         ├─ 一方看空 → HIGH 暂停
         └─ unknown → fail-closed 拦下
第 2 层  T5 硬约束（本次新增）★
         └─ pos20≥70% 且 dev_ma20<1% → 降级：超跌策略暂停
第 3 层  个股信号
```

**T5 的价值在于它完全不看模型怎么判** —— 只用价格。这正是 9/21 需要的：那天双方都判"偏多"，T5 说"高位滞涨"。

### 6.2 建议的实现

```python
def high_level_stall(bars, i):
    """T5 高位滞涨：20日区间分位≥70% 且 收盘对MA20偏离<1%"""
    w = bars[max(0, i - 19): i + 1]
    lo = min(x["low"] for x in w)
    hi = max(x["high"] for x in w)
    if hi <= lo:
        return False
    pos20 = (bars[i]["close"] - lo) / (hi - lo) * 100
    ma20 = sum(x["close"] for x in bars[max(0, i - 19): i + 1]) / len(w)
    dev = (bars[i]["close"] / ma20 - 1) * 100
    return pos20 >= 70 and dev < 1
```

### 6.3 使用建议

| 项 | 建议 |
|---|------|
| 触发后动作 | **降级**（暂停超跌策略），不是"清仓" |
| 时长 | 触发状态下持续生效，直到条件解除 |
| 9/21 效果 | 触发 → 6 只超跌标的不会进推荐 |
| 代价 | 1500 天里触发 135 天（9% 覆盖率），代价可控 |

**注意：是"降级"不是"看空"。** T5 说的是"这里风险偏高"，不是"一定跌"（64.8% 而非 100%）。

**固定 `dev=1`，扫 `pos20`：**

| pos20 | 事件数 | 下跌率 | 均收 | vs 基线 |
|-------|--------|--------|------|---------|
| 55 | 79 | 57.0% | -0.05% | +9.2pt |

**55 到 85 全程正超额，且呈单峰平滑曲线**（峰值在 70 附近，两侧缓降）。

如果是过拟合，曲线会**陡峭**（只有某个点好，旁边就崩）。**这里是平滑的 —— 说明捕捉到的是真实的市场结构，不是噪声。**

### 7.3 结论二：70 这个位置选得不错

曲线呈**单峰**，峰值恰在 **pos20 = 70**（+17.1pt）。

- 低于 55：位置不够高，"高位"含义弱化
- 高于 85：事件数掉到 10 个，统计不稳
- **70 是"足够高"且"样本充足"的平衡点**

这不是我调出来的，是**先按常识定 70，再扫参数发现它刚好在峰上**。这种情况可信度高。

### 7.4 结论三：`dev` 阈值可以放宽，但 1 最锐

**固定 `pos=70`，扫 `dev_ma20`：**

| dev_ma20 | 事件数 | 覆盖率 | 下跌率 | 均收 | vs 基线 |
|----------|--------|--------|--------|------|---------|
| **1** | 54 | **9.0%** | **64.8%** | **-0.51%** | **+17.1pt** |
| 2 | 71 | 21.6% | 57.7% | -0.28% | +10.0pt |
| 3 | 65 | 30.8% | 58.5% | -0.36% | +10.7pt |
| 4 | 63 | 34.8% | 58.7% | -0.11% | +11.0pt |

**dev < 1 的区间样本不足**（说明"贴均线"这个条件筛掉了绝大多数情况）。

**dev 从 1 放宽到 4，超额从 +17.1pt 降到 +10pt，但覆盖率从 9% 涨到 35%。**

这是一个**取舍**，不是对错：

| 选择 | 特点 | 适用 |
|------|------|------|
| **dev = 1** | 最锐利，只覆盖 9% | 想精准打击，宁可少拦 |
| dev = 3 | 覆盖率 31%，超额 +10.7pt | 想要更多保护，接受钝一些 |

**我建议先用 `dev = 1`**（原案），因为它区分度最高。如果实盘发现漏太多，再放宽到 3。

### 8.4 跨指数验证：**失败了 —— T5 不能推广到其他指数**

这一项我原本没打算测（觉得上证成了就够了）。测完发现**必须写进来**，因为它是一条**否定结论**。

用同一套参数（pos20 ≥ 70、dev < 1、gap ≤ 3、持有 5 日）在 5 个指数上跑 1500 天：

| 指数 | 触发日 | 独立事件 | 覆盖率 | 下跌率 | 事件均收 | vs 基线 | p 值 | |
|------|--------|---------|--------|--------|---------|---------|------|---|
| **上证指数** | 135 | **54** | 9.0% | **64.8%** | **-0.51%** | **+17.1pt** | **0.17%** | ✅ |
| 中证500 | 79 | 35 | 5.3% | 60.0% | -0.53% | +12.2pt | 5.83% | ⚠️ |
| 沪深300 | 55 | 33 | 3.7% | 57.6% | +0.06% | +6.9pt | 25.57% | ⚠️ |
| 深证成指 | 50 | 29 | 3.3% | 55.2% | -0.18% | +5.1pt | 38.77% | ⚠️ |
| 创业板指 | 27 | 14 | 1.8% | 50.0% | +0.60% | **-1.1pt** | 62.80% | ❌ |

**只有上证显著（p=0.17%）。其余四个全部不显著，创业板甚至是负超额。**

#### 先排除"样本不够"这个解释

我第一反应是"其他指数触发太少"。查了一下 **pos20 ≥ 70% 的占比**：

```
上证指数  36.7%    中证500  33.1%    沪深300  29.9%
深证成指  32.4%    创业板指  30.1%
```

**上证不是最高的。** 各指数"走到高位"的频率差不多，但只有上证在"高位 + 贴均线"这个组合下有区分度。**不是触发不足，是信号本身在其他指数上不成立。**

#### 再看参数曲线形态（印证）

| 指数 | pos 55→60→65→70→75→80→85 的超额走势 | 形态 |
|------|-----------------------------------|------|
| 上证 | 9.2 → 10.2 → 13.9 → **17.1** → 14.7 → 9.4 → 12.2 | 单峰平滑 ✅ |
| 深证 | 7.0 → 4.0 → 3.0 → **5.1** → 3.9 → -4.5 → -8.0 | 锯齿 📉 |
| 创业板 | 5.6 → 4.7 → 3.3 → -1.1 → 3.3 → 8.3 → -5.9 | 乱跳 ⚠️ |

**上证的曲线是平滑单峰；其他指数是锯齿状，没有稳定结构。** 这和"p 值不显著"是同一个事实的两种呈现 —— 上证的信号是真结构，其他指数上看到的是噪声。

#### 9/21 那天只有上证触发

```
上证指数   pos20 = 70.3%   dev = +0.61%   → 🔴 触发
中证500    pos20 = 74.6%   dev = +1.30%   → ⚪ 未触发（dev 超阈值）
深证/沪深300/创业板          pos20 < 70%    → ⚪ 未触发
```

**换句话说：如果 9/21 那天的决策看的是深证或创业板，T5 不会拦下任何东西。**

#### 这条否定结论的意义

**T5 是"上证指数专用规则"，不是"大盘通用规则"。**

在报告里这比一条假阳性重要的多 —— 如果我只看上证就宣布"找到了通用避险规则"，大海拿去套在深证上，会发现完全没用，然后整个方案的信任就崩了。

而且有个合理的解释：**上证和 9/21 那次下跌的驱动因素（大盘权重、银行/白酒等抱团股）高度相关**。创业板是成长股逻辑，驱动力不同，所以"高位滞涨"在它身上不预示下跌。

**落地时的约束：**
- T5 只能挂在上证指数上
- 深证/创业板要另找规则（本次没找到，不是没试）
- **不要把这个结论对外说成"找到了大盘避险信号"**
