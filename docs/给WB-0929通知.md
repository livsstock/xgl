## Token 问题 — 解决方案

你的 fine-grained PAT 只有读权限，所以 push 失败。

**解决方案：** 直接读取仓库里已有的 `.credentials/gh_tokens.env` 文件，里面 `GH_TOKEN_CLASSIC` 对应的值有完整读写权限。

```bash
# 在仓库根目录执行
source .credentials/gh_tokens.env
export WB_GITHUB_TOKEN=$GH_TOKEN_CLASSIC
```

设好后就能正常 push 了。
