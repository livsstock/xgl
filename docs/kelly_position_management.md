# 凯利准则仓位管理方案 (Kelly Criterion)

## 公式与原理
- **凯利公式**: f* = (bp - q) / b
  - p = 胜率, q = 1-p, b = 盈亏比
- **半凯利策略**: 实际仓位 = f* / 2，降低波动风险
- **核心思想**: 在期望为正时，按最优比例分配资金，避免过度冒险

## 样本量修正
- n < 50: 仓位砍半（数据不足以支撑结论）
- n < 100: 仓位打7折
- n ≥ 100: 全额执行

## 风控约束
- **总仓位上限**: 50%（5万）
- **单只上限**: 20%（2万）
- **大盘风控**: 大盘开关关闭时，所有仓位再减半
- **止损纪律**: -8%硬止损，10日时间止损

## 与金字塔建仓法叠加
凯利给出最大仓位上限，金字塔法给出分批建仓节奏：
1. 凯利计算最大仓位 → 例如盛和15%（15,000元）
2. 金字塔分3批建仓：
   - 第1批(-5%试): 5,000元
   - 第2批(-10%加): 5,000元
   - 第3批(-15%重): 5,000元
3. 退出: +5%止盈 / -8%止损 / 10日强平
